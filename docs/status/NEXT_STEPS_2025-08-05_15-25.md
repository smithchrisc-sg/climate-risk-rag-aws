### 🚨 Critical Build Requirements
- **Python Version**: ALWAYS use `python3` command - never use `python`
- **Layer Building**: Use ONLY `layers/knowledge-graph-layer/build_layer.sh` script
- **Layer Validation**: ALWAYS verify proper `/python/` directory structure before deployment
- **Dual Layer Configuration**: KG functions MUST have both knowledge-graph-layer AND database-layer
- **Version Control**: Update CDK references to match deployed layer versions immediately after deployment

### Layer Build Process Validation Checklist
1. ✅ Use correct build script (`build_layer.sh`)
2. ✅ Verify `/python/` directory structure in ZIP
3. ✅ Confirm all required dependencies present
4. ✅ Test layer with simple import validation
5. ✅ Update both Lambda functions with dual layers
6. ✅ Update CDK configuration to match deployed versions
7. ✅ Run end-to-end pipeline test for validation
