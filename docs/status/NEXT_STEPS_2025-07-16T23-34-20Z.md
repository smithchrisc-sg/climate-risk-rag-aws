## Cost Considerations

When implementing these next steps, be mindful of the costs associated with AWS services:

### Textract Costs

- **Cost per page**: Textract charges per page processed
- **Async vs. Sync**: Async operations have different pricing
- **Feature types**: Different feature types (e.g., TABLES, FORMS, LAYOUT) have different costs

**Cost Reduction Strategies:**
- Use the `--skip-lambda-invocation` flag during testing
- Limit the number and size of test documents
- Clean up test documents promptly

### SNS/SQS Costs

- **API calls**: Costs for API calls to SNS and SQS
- **Data transfer**: Costs for data transfer between services

**Cost Reduction Strategies:**
- Batch messages when possible
- Monitor API usage

### Lambda Costs

- **Execution time**: Costs based on execution time and memory allocation
- **Invocations**: Costs per invocation

**Cost Reduction Strategies:**
- Optimize Lambda function code for efficiency
- Choose appropriate memory allocation
- Use provisioned concurrency only when necessary
