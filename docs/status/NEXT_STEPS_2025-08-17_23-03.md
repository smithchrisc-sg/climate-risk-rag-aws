**Problem:** Currently only processing single-word entities due to timeout issues
**Impact:** Missing important locations like "New York City", "United Kingdom", "South Asia"

**Implementation Strategy:**
- **Phase 1:** Implement whitelist approach for known multi-word locations

  - Test with controlled set of 50-100 common locations

- **Phase 2:** Optimize FTS query structure for phrases
  - Implement proper phrase queries with quotes
  - Add query timeout handling and fallbacks
  - Batch processing for multi-word entities

- **Phase 3:** Smart phrase detection
  - Use NER confidence scores to filter high-quality phrases
  - Implement incremental processing for complex entities
  - Add caching for successful multi-word alignments

**Files to Modify:**
- `layers/knowledge-graph-layer/python/utils/FTSSparqlQueryBuilder.py`
- `layers/knowledge-graph-layer/python/utils/ContextualEntityAligner.py`
